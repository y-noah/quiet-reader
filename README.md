# New

面向文字内容的 Android 个性化热门阅读器。推荐与语义处理在手机本地运行，无需部署服务端或填写 AI Key。

## 当前版本

**1.0.0（versionCode 49）**，包名 `app.quietreader`，沿用原签名，可覆盖升级保留数据。安装包 `New-1.0.0.apk` 通过本仓库 GitHub Releases 提供。后续以1.0.0为版本基线递增。

- 单一推荐首页，圆点和顶部下拉刷新换批，底部不无限追加；去掉分类、总榜、稍后读和应用内品牌文字。
- 两个随包本地模型参与兴趣排序与事件判断；内容、平台偏好分别记录，点击本身不直接计为喜欢。
- 当前展示批次主动预缓存，换批后清理旧缓存；保留登录、偏好、历史及阅读位置。
- 图文与讨论统一排版，正文内视频保底适配，视频流不作为默认内容方向。
- 来源页与阅读页共享本机会话；来源支持双向滑窗，保留滑动并隐藏纵向滚动条。
- 修复刷新动画结束时序、知乎慢展开误读摘要、虎扑隐藏节点干扰正文校验，以及读取超时、导入线程和预读接管问题。

## 验证与限制

已在 Find X7 Ultra / Android 16 上保数据升级，验证当前知乎、虎扑读取、重新读取、来源导入和重启后的阅读。60次前台、4次后台归属内存采样中，观察最高约833MiB，后台末次约325MiB；常规操作检查通过，不等于所有瞬时负载峰值的保证。

去重优化目前暂停，仍可能有漏合并。已测登录路径正常，不代表全部登录专属内容与完整分页均已覆盖。拔线耗电、温升和个性化效果需要实际使用观察。不会绕过来源登录、验证码或付费限制。

具体记录见 [真机检查](docs/validation/phone-closeout-20261029.md)、[登录与性能补验](docs/validation/phone-login-performance-20261029.md) 和 [需求文档](docs/requirements/personalized-hot-topics-v1.md)。历史报告只证明对应版本，不将各轮数量累加为最新包全量通过。

## 开发

Android compile/target SDK 36，Java 17语言级别，JDK 21、Gradle 8.11.1、NDK 28.2；最低兼容SDK 26不代表以旧系统为验收设备。

生产代码在 `app/src/main`，测试位于 `app/src/test` 和 `app/src/androidTest`。本地模型准备、验证与打包工具在 `scripts/models`；模型清单在 `app/src/main/assets/local-ai-manifest.json`，模型权重按清单准备后以 `-PbundleLocalModels` 打包。模型、SDK、构建产物和私有签名材料不进入Git。

现有脚本使用本机工具目录，换电脑需配置对应路径。签名密码使用本机Windows DPAPI保存；覆盖已安装版本需要原签名。详细开发流程见 [DEVELOPMENT.md](DEVELOPMENT.md)。

应用只声明联网与网络状态权限，无广告/分析SDK，不导出Cookie或同步账号。
