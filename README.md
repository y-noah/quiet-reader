# News

个人使用的安卓热搜阅读器，原名「静读」。原生 Java 界面，使用系统 WebView，不自带浏览器内核，不需要部署服务器。

## 安装与使用

原稳定回退基线 **news 0.3.15** 保留不变。安装包与对应源码快照位于 `artifacts/stable-0.3.15/`，校验值见该目录 `BASELINE.txt`。事件时间线探索保留在 `experiments/` 和独立测试组件中，不进入交付 APK；在事件信息整合可用前，首页暂不提供搜索框。

本轮版本为 **News 0.3.24（versionCode 35）**，验证记录见 `VERIFICATION-0.3.24.md`。底部平台栏由56 dp压紧到48 dp，向下阅读时隐藏、向上回看时恢复；隐藏不改变正文视口高度，回到榜首或从正文返回时显示。修复IT之家误取透明占位图的问题，正文与大图预览读取真实原图，已知占位图不再误报成功。包名、签名、登录数据与阅读偏好不变，可覆盖安装 `artifacts/News-0.3.24.apk`，不要先卸载。历史版本和稳定回退基线保留，无新依赖、模型、token付费或服务器。

沿用0.3.23的「综合推荐 Top100」，平台及榜内名次以小字显示在标题上方，1–100名共用同一文字对齐列。六个独立平台为「知乎、爱范儿、财联社、什么值得买、虎扑、微博」，默认启动知乎；极客公园仍参与聚合，不再有独立标签。底部「总、知、爱、财、值、虎、微」保留圆头单字、无背景块、24 dp绘制尺寸及48 dp点击区域。

综合页接入截图指定的13个来源：知乎、值得买三小时榜、微博、虎扑、果壳、极客公园、豆瓣热门话题、IT之家日榜、爱范儿、掘金、华尔街见闻、财联社、少数派。最多3路并发，先显示已取得的结果，22秒本轮截止；使用原有每平台小型榜单缓存，15分钟内复用，24小时以上不参与排序。可打开「来源状态 · 排序说明」查看每个平台的真实成功、缓存、失败和快照时间。微博匿名API可能拒绝访问，缺源不伪造。

排序已按“综合热点优先、垂直内容补充”重做，不把掘金与知乎/微博同位次等权。基础分为 `1100/(10+榜内名次)`，乘推荐权重：知乎/微博1、豆瓣0.8、虎扑0.7、财联社/华尔街见闻0.65、IT之家0.5、掘金/极客公园0.35、少数派0.3、值得买0.25、果壳/爱范儿0.2。权重是个人阅读优先级，不是平台流量统计或精确热度换算。果壳首页精选、爱范儿最新文章明确标为非热榜。

同完整规范化标题跨平台合并，最高分加其他平台各40%。知乎/微博单源最多主导20条，豆瓣/虎扑/两家财经各12条，其余各8条，总计最多100条；不足不放宽上限凑数。缓存年龄每15分钟一档，每12小时分值减半，超过24小时不参与；这是快照获取时间，不是事件发生时间。首页含缓存时明确标出，来源数量不等于实时请求成功数。保留小数、正负号等数值区别；不同措辞的同一事件可能仍重复，不作语义事件聚类或社会事件重要性判断。多来源条目可选择原平台继续读，返回综合页保留位置。豆瓣话题列出首批图文入口，不声称完整讨论，原帖可能受限。

保留 0.3.14 的当前视口最多三篇正文预测预读，串行执行，点击可接用进行中的请求；切平台或离开前台取消旧任务。预读不下载图片，正文缓存按保守估算封顶 2 MiB，已读图片字节缓存封顶 2 MiB；这是缓存预算，不是整个 App/WebView、图片解码和临时网络缓冲的运行内存上限。不新增正文磁盘数据库，进程结束后不保证正文缓存保留。

已确认的视频主题从榜单及其持久缓存移除，不再显示需额外返回的过滤中间页。主帖优先展开，长回答可用上下条、目录及向上回滑时出现的下一条入口跳转。长网址缩成可点击短标签，长按可查看和复制完整地址。更多菜单的「阅读设置」可调整字号、字体、行距、深浅模式、背景和链接配色；六平台栏及原有来源登录流程保留。

可直接覆盖安装同签名旧版，不要先卸载。已知限制：平台登录、知乎真实账号后续回答尚未全面认证；短文刚展开时，图片迟到仍可能引起布局位移。稳定版表示当前已验证的阅读流程可交付，不保证所有平台页面、账号及手机均无问题。完整证据见 `EXPLORATORY-QA.md` 和 `IMAGE-LAYOUT-QA.md`。

0.3.11 修复微博相同配文、不同配图被错误合并的问题，并让已知微博缩略图在主动点开时请求原站的大图版本。正文仍保留轻量缩略图；实测首图预览从 360×615 提升为 1200×2050，关闭后原位置保留。当前验证与未覆盖范围见 `VERIFICATION-0.3.11.md`、`WEIBO-READER-JOURNEY-QA.md`。全平台深浅配色、视频过滤以及此前来源导航恢复仍保留。实时榜单不以旧截图的商品或排序作固定验收值。

签名安装包：`artifacts/静读.apk`。0.3.1 连续阅读返回榜单的修复与验证见 `VERIFICATION-0.3.1.md`；0.3.0 紧凑界面改版见 `VERIFICATION-0.3.0.md`、`design-qa.md`；0.2.8 的商品主图和迟到回答回归见 `VERIFICATION-0.2.8.md`；三小时好价榜见 `VERIFICATION-0.2.7.md`；完整需求矩阵见 `VERIFICATION-0.2.1.md`。旧版验证记录不是新版认证，本版也没有普遍秒开或所有平台登录已解决的结论。

1. 将 APK 传到安卓手机，打开安装。按系统提示允许此次安装来源。
2. 选择综合、知乎、爱范儿、财联社、什么值得买、虎扑或微博，点击榜单进入话题或正文。爱范儿使用最新文章源，不伪装成热榜。什么值得买接入官方「3小时最热」公开好价榜，保留价格、用券条件、商城和时间；公开榜与 App 的逐项排序是否完全一致尚未验证。
3. 正文采用静读自己的排版，没有原站推荐流、下载按钮或自动拉起其他 App 的行为。
4. 右上角更多菜单提供刷新、外观、来源 / 登录，平时不占用阅读区域。需要登录时自行在平台页面操作；榜单入口点「返回热榜」会自动刷新，正文入口点「读取到静读」回到自有排版。微博首次访问有时需要先打开来源网页建立会话。密码由平台页面处理；静读没有自己的账户系统，不导出平台 Cookie。不同平台仍可能要求验证或拒绝嵌入式浏览器。
5. 阅读页右上菜单可调整字号；外观支持跟随系统、浅色和深色。各平台长正文/多段内容提供独立展开和收起，知乎支持底部续读入口及向下滚动触发追加；平台要求登录时会明确提示，保留已读回答。
6. 收藏入口已移除，不会删除旧收藏数据。首页搜索暂时取消，不提供事件时间线功能；本次浏览仍按平台记住榜单位置，读完返回无需从榜首重新找。底部为七等分单字栏，也可从更多菜单「全部平台」切换。榜单缓存标明时间；最近打开的正文有有界内存缓存，重开可恢复位置，进程被结束后不承诺正文离线保存。
7. 图片可能稍后显示；即使图片空白，也可以点图注“查看大图”。弹窗会显示加载或失败状态，并提供单图重试；关闭回到原文，不重新加载正文。只有实际解码后才显示成功状态。

目标系统为 Android 8.0 及以上；最新实际运行记录以 `EXPLORATORY-QA.md` 的 0.3.14 节为准，之前 0.3.11 见 `VERIFICATION-0.3.11.md`。本轮为专用API35模拟器测试，未重测API26，也未声称覆盖所有厂商机型。请保持系统 WebView 更新，以兼容来源网站的现代页面。

## 能力边界

- 静读只能整理平台实际提供给当前设备会话的内容，不绕过登录、付费、验证码或访问限制。
- 论坛回复、知乎回答等动态内容只展示已加载部分，并明确提示。知乎续读按真实来源页追加和去重，不把“这次没有新增”说成“全部读完”；真实账号登录后的追加仍需认证实测。对于识别到的同一帖子「下一页」链接，可继续使用自有阅读页读取。
- 默认过滤能明确识别的视频主题、视频卡片和独立视频回答；未知类型在打开后确认，确认的视频主题从列表及缓存读取结果隐藏7天。不会根据标题含“视频”误删文字讨论，也不把视频帖的回复冒充正文。知乎问题的附带视频不连带删除文字回答，普通文章的嵌入播放器不会进入静读正文。结构变化或尚未加载的媒体仍可能漏判。
- 登录/来源页面是用户主动打开的原站页面，可能仍含平台自身提示；其内容不会被当作静读的阅读界面。新系统开启网页深色适配，但原站禁用变暗、验证码或旧系统可能保留原色；不对商品图片强制反色。
- 按个人使用需求已移除 Hacker News 等国外平台入口；保留旧数据格式兼容，不删除已有本机数据。
- 微博改用官方移动登录入口，允许明确列出的新浪认证跳转，并仅对微博来源视图允许第三方 Cookie。表单已能显示，但尚未完成真实账号认证与重启保留验证，不能保证解决全部账号的登录问题。
- 华尔街见闻仅整理会话可取得的正文，不绕过订阅/付费；什么值得买使用官方三小时好价网页，而非 App 私有接口。来源无法返回明确的三小时榜时显示失败，不拿十二/二十四小时榜或推荐商品充数。旧版什么值得买榜单缓存不用于新版；其他榜单、收藏和登录会话保留。

## 本地开发

在项目目录的 PowerShell 中运行：

```powershell
./scripts/bootstrap.ps1
./scripts/build.ps1
./scripts/release.ps1
```

全部工具位于 `.tools`，脚本只设置当前进程环境变量。`release.ps1` 创建项目专用签名，密码通过 Windows DPAPI 保存在 `.tools/signing/password.xml`，不要公开 `.tools`。后续覆盖安装必须保留同一签名；换电脑前应妥善迁移签名及其密码，而不是重新生成。

测试：

- `build.ps1`：JVM 单元测试、Debug 构建、Lint。
- `test-release.ps1 -KeepData -Mode sources -Source SMZDM -SmzdmImageJourney`：在真实刷新榜单中定位固定原失败商品，验证正文主图、预览和关闭保位；已离榜则明确未覆盖，不造条目。`-SmzdmImageProbe` 独立观察同商品来源图片归属，仅诊断，不冒称阅读验收。
- `test-experience.ps1`：在电脑专用模拟器运行独立用户旅程，包括长回答收起定位、字体/主题切换、返回恢复、小屏 200% 系统字号、加载中退出、深色图片与断网；每次保存独立截图目录及测试 APK 哈希。不需要手机安装。
- `test-experience.ps1 -Mode predictive`：有界预读、请求接用、取消迟到回调、视频预分类、设置实际生效和长回答跳转。只有单独标记的虎扑计时使用真实网络，其余为明确合成输入。不能据此声称六平台或用户手机全部秒开。
- `test-experience.ps1 -Mode images`：只跑新增图片图注、失败、重试、连续点击、深色对比和关闭后迟到回调检查；`-Serial emulator-5558` 验证 Android 8。使用明确标注的受控图片，完整 `all` 模式也包含这两组旅程。
- `test-experience.ps1 -Mode image-layout`：延迟真实合成 PNG 字节，分别观察初展、图下、中段和底部；39 项检查包含真实解码与已滚动段落定位，初展位移单独记录，不以通过数冒称零跳动。
- `test-experience.ps1 -Mode smzdm-cache`：直接通过生产 Repository 验证三小时榜旧缓存失效和新缓存写入，15 项检查；精确恢复所改三键，不访问 Cookie 或网络。与 `all` 模式分开运行。
- `test-local.ps1`：一键串联来源页复用、动态读取回归、体验测试、正式包构建、正式包 UI 测试、断网测试。先启动项目模拟器；本脚本不接触手机，但仍需人工看本轮截图，不代替真实账号测试。
- `test-navigation-recovery.ps1`：8 个本地受控旅程 / 59 检查，真实 WebView 导航验证 HTTPS 升级、外部/自定义 scheme 拦截、循环上限、错误提示保留及新合法页面恢复。无有效来源地址的恢复用 about:blank 验证同一分支，不冒充 null URL 专证；不是实网账号认证或全部网页兼容性保证。纳入 `test-local.ps1`。
- `release.ps1`：单元测试、压缩混淆 Release 构建、签名校验，输出 `artifacts/静读.apk`。
- `test-release.ps1`：默认使用专用 `emulator-5556`，传 `-Serial emulator-5558` 可测试 Android 8 专用模拟器。默认重置该模拟器应用数据，传 `-KeepData` 保留数据覆盖安装；强制取得真实榜单再验证实际 Release APK。禁止用于真实手机。
- `test-release.ps1 -KeepData -Mode sources -Source WEIBO -WeiboReaderJourney`：在专用 API35 模拟器验证真实文字展开、首图解码、预览同图及分辨率、关闭前后未移动位置，并观察原站同图。实际卡片没有原帖入口时明确未覆盖，不把此分支算通过；不代表全部图片或账号登录已认证。
- `start-emulator.ps1`：启动项目 Android 15 模拟器，默认使用软件渲染并关闭 Vulkan 作宿主兼容性排查；`-Gpu` / `-EnableVulkan` 可选择其他启动方式。参数仅在新启动时应用，不改变运行中的设备；每轮独立保留参数及日志，不清除应用数据，不代表已证明旧崩溃根因。
- `test-offline.ps1`：在上述测试之后运行，强制停止测试应用并关闭专用模拟器网络，确认无默认网络后验证缓存和持久化；结束时恢复模拟器原网络状态。
- `start-min-sdk.ps1`：在已安装 API 26 官方镜像后启动独立的 `emulator-5558`，用于最低系统版本测试。
- `test-experience.ps1 -Mode audit -Serial emulator-5558`：在上述旧系统模拟器上检查续读保位、多图折叠与加载竞态；默认仍测试 `emulator-5556`。脚本同时核验虚拟设备和项目 AVD 名称，拒绝真实手机。
- `test-experience.ps1 -Mode board-return`：真实滑动到榜单中段、打开正文并返回，以及搜索后返回、跨平台与外观重建、受控刷新重排的上下文保持；输入是明确合成缓存，不当作平台认证证据。也纳入 `all` 模式。
- `test-release.ps1 -KeepData -Mode sources -Source ZHIHU`：仅补验真实知乎回答，避免每次重跑全部平台；省略 `-Source` 会检查全部七源。匿名样本通过不等于登录成功或后续全部回答可取。
- `test-release.ps1 -KeepData -Mode sources -Source TIEBA`：仅补验贴吧真实正文与图片，测试当前正式 APK，不把构建输出的 debug 误算作发布包。
- `test-release.ps1 -KeepData -Mode sources -Source WEIBO -WeiboProbe`：自动正文失败后继续真实点击来源协助、观察跳转及手机/桌面模式、尝试读取；保留自动路径失败，不因恢复页打开而改判整轮成功。只记录安全来源地址和结构指标，不读取或导出账号、Cookie、原站 HTML。
- `test-release.ps1 -KeepData -Mode sources -Source WALLSTREET`：单独观察华尔街见闻；在选中正文通过后，另将首张非表情图片移入视口，最多观察 12 秒，分别记录文字可读与图片实际解码。七源均可按其来源枚举名选择；一次首图通过不代表全文所有图片通过。
- 上条加 `-WallstreetOriginal` 可复验本轮曾出现空白的固定文章和首图，仍从真实榜单卡进入并核对地址；文章退出榜单时会失败，不会静默替换样本。
- 实网来源测试将展开检查绑定到实际选中的卡片，并在重排后重新核对触屏位置；先记录阶段/失败原因再截图，运行前保存 runId 与包哈希，中断后按已知路径有界取证。未生成最终通过结果或截图恢复失败时仍返回失败。
- `test-latency.ps1`：在专用模拟器对固定贴吧/知乎页面各测两次，记录加载事件与正文指纹，不保存源 HTML 或 Cookie；4 次成功才返回成功。它是有观察开销、共享缓存的诊断，不是通用提速或正文视觉验收。
- `test-dynamic-reading.ps1`：独立受控来源回归，通过真实生产解析/回调检查相同数量但内容变化、单条新增、持续增长、无新增和登录限制；5 例 36 项全部通过才成功。支持 `-Serial emulator-5558`；本地拦截合成输入不是实网认证证据。
- `test-session-reuse.ps1`：9 例 97 项来源页复用与生命周期回归，涵盖实际首批到续读、单回答链接回退、跳题拒绝与提示、切换释放及立即取消；新增真实触摸触发无新增、第三答迟到后点击重试和展开正文，检查提示与暂停状态一致。支持 `-Serial emulator-5558`，合成页面不代表真实登录已验证。
- `SmokeInstrumentation`：Debug 解析/阅读状态及匿名实网测试；来源观察成功不等于已验证账号登录。

## 隐私与依赖
