# News

个人使用的原生 Android 热搜阅读器，使用系统 WebView，无服务器。

## 当前版本

**0.3.35 本地候选版（versionCode 46，未发布）**，安装包 `artifacts/News-0.3.35.apk`。沿用包名 `app.quietreader` 和原签名，可直接覆盖安装。验证记录见 `VERIFICATION-0.3.35.md`。

- 来源登录页默认采用滑窗：保留 1280 × 960 dp 的桌面画布，可上下左右拖动，点“窗口居中”复位。到窗口底部后再次上滑可继续滚动网页；点击与输入由网页正常处理。无需依赖网站允许缩小，也不持续改写网页布局。固定滑窗不提供缩放切换，避免页面反复缩放；旋转屏幕后恢复窗口位置。

- 知乎首条回答默认展开，段首仅保留一个展开/收起，段尾仅保留一个下一条；移除悬浮重复入口。提前约一屏续读，状态和重试留在正文末尾。
- 本机保存最近阅读记录、已加载内容及折叠状态，重新进入同一篇时恢复位置；榜单显示已读。记录最多30篇且总量有限，过大的正文只保存位置。
- 正文图片预留尺寸，尺寸未知时使用固定预览框；大图支持上一张/下一张、未放大时横滑切换、双指缩放、长图滚动和原地重试。

- 知乎正文提取前先操作来源页的“显示全部 / 阅读全文”，等待异步补充内容；应用内的折叠段落使用展开后的正文。
- 来源页保存手机版/桌面版选择，榜单请求、动态正文与新续读页面沿用同一浏览模式。已访问来源页的平台优先通过 WebView 读取，复用本机网页会话；保留页面续读时不再强制更改浏览模式。
- 知乎备用接口返回 401/403 时继续尝试网页加载，只有页面实际出现登录提示才按登录限制处理；未取得新内容仍保留已读回答。

- 默认进入知乎。底栏为「知、微、虎、财、V」，其余平台可从“全部来源”浏览；保留12个平台的独立榜单和登录会话。V2EX继续读取 `https://www.v2ex.com/?tab=hot`。
- 删除总榜及其聚合加载、跨平台排序、同题合并和专用测试工具。旧页面状态回到知乎，不清空各平台缓存或登录信息。
- 底栏改用系统正规中文字形，统一常规字重与基线，保留原颜色；选中项用短线标记。默认20 dp，随系统字号最多放大至26 dp，以适应48 dp点击区域。
- 升级保留12个有效来源的缓存、收藏和网页会话；端点改变时不会把旧接口缓存当作新榜单。
- 少数派、爱范儿为文章源，小红书为发现页样本，均没有已验证的全站热榜，保留各来源原有分类与数据。
- 百度搜索、贴吧话题、抖音、B站、小红书直接使用共享会话网页浏览，支持网页缩放、HTTPS外链和视频全屏返回。“登录滑窗”打开稳定的双向登录窗口，返回后重新加载来源。
- 更多菜单提供刷新、来源/登录及阅读设置。支持深浅色、阅读字号与图片预览。

- 微博优先读取官方热搜 `/ajax/statuses/hot_band`，保留旧接口及网页回退；兼容旧缓存，主动刷新绕过本地 HTTP 缓存。刷新中显示进度，失败保留原数据与时间，并在列表上方提供来源页重试入口。取消的请求不会覆盖缓存。

## 边界

仅展示当前会话能够获取的内容，不绕过登录、验证码或付费限制。自动测试中的合成缓存和会话内分页不代表真实账号认证成功。系统字体可能随手机厂商略有不同。Android 8.0起支持；当前实测范围见版本验证记录。

## 开发与验证

```powershell
./scripts/bootstrap.ps1
./scripts/build.ps1
./scripts/start-emulator.ps1
./scripts/test-local.ps1
./scripts/release.ps1
./scripts/test-release.ps1
```

工具在 `.tools`，签名密码由 Windows DPAPI 保护，不进入仓库或源码包。构建和当前验证脚本可用 `-GradleInit` 指定本地初始化脚本（`build.ps1` 通过 `-Tasks '-I',路径,任务`）。

`test-current.ps1` 支持五源迁移/导航、动态读取、知乎分页、合成会话复用及阅读位置旅程。`test-release.ps1` 验证实际压缩签名包。均只操作专用模拟器，不操作手机。历史文档记录历史版本，不代表当前支持功能。

## 隐私与依赖

只有 INTERNET 和 ACCESS_NETWORK_STATE 普通权限，无分析/广告 SDK，不导出 Cookie，不同步账号，Android备份排除应用数据。

- jsoup 1.23.2，MIT；许可随包提供。
- Android NIO desugaring 2.1.5，GPLv2 with Classpath Exception；许可随包提供。
- 更多图标来自 Google Material Icons（Apache-2.0）。底栏使用系统字体，不额外打包字体资源。

百度搜索、贴吧话题和帖子、B站视频、抖音视频页默认使用来源专用手机排版，复用来源网页会话。顶部“原网页/手机排版”可切换；“登录滑窗”继续使用独立的双向滑窗，不注入阅读排版。

抖音原播放器无法初始化时，从当前网页已提供的公开视频数据建立独立手机阅读区，支持点击播放、全屏、完整描述、评论翻页和楼中楼回复。优先使用来源提供的 720p H.264；不提前下载视频。来源内部重建页面不会清除阅读区，登录返回会恢复热榜入口。私密、付费或明确要求登录的视频不启用此后备播放。切回原网页会停止后备视频并取消评论请求。
