# New 1.0.21

基于远端 1.0.20（ab6f8ad）继续迭代。

## 改动

- 首页首次显示后，正文预热结束不再重新发布当前列表。从文章返回时保留当前条目及顺序，已读状态由现有浅灰样式展示；主动刷新时继续排除已读原文。后台可以准备候选和缓存。
- 新增奇客 Solidot 的热门文章及 InfoQ 中文的技术文章 RSS。Solidot 不采集置顶推广；InfoQ 排除视频入口并明确为最新技术文章，不伪造热榜排名。正文使用统一阅读器及既有缓存。
- 数据库 12→13 只补充两个新来源，保留已有来源开关、偏好、登录和已读数据。新来源可在设置中关闭。
- 续载回答、评论和话题预取结果时协调更新正文 DOM，保留既有图片节点，减少图片重复加载。相同地址的多张图片分别保留；延续 1.0.20 的每帖图片 referer 和失败重试处理。
- 调整串行预取顺序，先准备当前页可直接提取的正文，再处理动态网页，最后准备未来批次；不改变推荐排序，不增加网络并发或后台常驻任务。
- 修复相同位置的反复布局回调不断延后正文预取、暂停图片预热的问题；仍保留实际滑动时的节流和有限缓存预算。
