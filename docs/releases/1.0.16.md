# New 1.0.16 试用：有限推荐与正文会话恢复

2026-11-12，versionCode 65。此版本用于试用 75 条推荐上限。

## 推荐规则

- 推荐过程从启用来源的当前候选取最多 300 条；搜索继续可以查找完整来源池，搜索结果不等于推荐名单。
- 本机兴趣样本、已缓存语义向量及平台偏好决定筛选与排序，来源热度不决定名单内的排序；没有兴趣证据时使用稳定顺序，继续积累偏好。
- 最多保留 75 条待推荐内容，每批最多 15 条，不足一批按实际数量展示。明确的内容负向匹配不用于补足数量。
- 首次完整模型计算可精炼尚未展示的临时选择，已经展示的内容计入这一轮额度；之后重排和已读变化不会把旧池的落选内容重新补入。
- 新内容加入时参与筛选，较相关的新内容可以替换尚未展示的选择；这类替换同样记录，不在后续刷新时拿旧内容补位。
- 已读、整批展示、视口曝光和兴趣反馈仍分别记录。翻过一批不会被记录为读过或不喜欢，但本轮不会反复显示。
- 用完后保留最后一屏，在列表末尾显示“暂时没有新的推荐内容”；下拉和圆点检查现有更新，没有合适的新内容就停止换批。来源采集仍按原间隔检查新内容。
- 推荐选择与已交付身份保存在本机数据库，重启、重新计算及七天展示记录过期都不会重新开放原来的旧尾部。时间显示模式同样停止循环。
- 数据库由 v11 升级为 v12，新增独立的推荐选择记录，保留原有偏好、登录、阅读记录和向量缓存。旧推荐快照通过来源策略版本重新构建。

## 正文加载处理

- 普通请求返回登录壳时，前台阅读先尝试共享登录状态的 WebView，再展示需要手动登录的提示。
- 动态页面已有“可见登录遮罩”检测，之前正文加载器未使用该结果，空登录壳会一直等待直至失败。本版在无正文时正确标记登录限制。
- 已有知乎账号的显式阅读，如果收到稳定的登录/空页面或 401/403，允许一次使用当前共享登录状态的新导航；重载继续使用原截止时间。
- 保留真实未登录、持续权限限制、429、证书错误和账号变化校验；不修改或清除用户登录信息，不把旧页面重新标为新账号缓存。
