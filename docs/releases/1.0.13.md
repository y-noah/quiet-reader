# New 1.0.13

版本号 62，沿用 `app.quietreader` 与原签名。2026-11-07 完成真机升级及前台验收。

## 变化

- 贴吧热议主题保留主题标题，关联原帖作为独立答案，各自评论归属原帖。
- 列表发布标题前准备首批 3 篇完整正文和图片，点击直接交接已准备内容；刷新期间保留可读旧列表。
- 阅读时继续提前准备后续批次，接近底部自然追加；加载更多作为兜底。追加保留已有答案 DOM、展开状态和位置。
- 收起只影响当前答案；分享图标调整为 14dp。
- 缓存覆盖主题快照、子正文和图片，支持进程结束后的磁盘恢复；按内容版本校验，保护读过的主题缓存。
- 列表恢复与准备期间使用骨架，稳定空结果才显示空态，修复短暂闪“尚无话题”。
