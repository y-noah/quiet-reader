# New 1.0.1

New 1.0.1 改善刷新、预缓存和已读状态，减少重复原文及单个平台占满列表的情况。

- 平台按独立份额分配并交错展示，候选数量不再决定平台占比；偏好在未读供给中生效。
- 修复刷新卡住、迟到批次覆盖、动画与实际展示不同步；保留首页与后续批次正文缓存，前台定时更新，后台停止预读。
- 已读标题恢复浅灰色；普通刷新、预缓存批次和重启恢复均过滤同平台同原文。正文链接与离线旧正文也记录已读，已读与兴趣学习分开。
- 补充纽约时报中文网免费公开中文来源，并修复来源读取、图片缓存和阅读跳转细节。
