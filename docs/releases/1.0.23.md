# New 1.0.23

- 新增量子位热门文章、雷峰网人工智能栏目，提供统一正文阅读和既有缓存。
- 平台“少推荐”改为降低选中机会，取消可能被固定为0的整数上限；真正热门的话题能部分抵消平台惩罚，重复少推荐不叠加到屏蔽。
- 各平台原始热度不相加，使用各自榜内位置；最新文章列表不冒充热榜。已读、关闭来源和内容屏蔽保持约束。
- 每页15条，总推荐窗口60条，四轮内容；预取上限60条。旧内容未读且有新内容加入时也保持最多60条。修复轮回展示后模型重新整理会把未选中的旧尾部补回来的边界问题。

- 修复首页在后台准备正文后自行插入条目，以及慢速预取失败后再次等待完整超时的问题。
- 修复微博搜索切换到移动站后偶发提示登录状态已变化的问题。页面导航参数的更新不会再让正文缓存失效，登录凭据变化仍会使缓存失效。

1067 项单元测试通过。两个新增来源在 Android 模拟器上通过联网取文和缓存检查。Find X7 Ultra 实测八轮首页刷新，并抽查知乎、虎扑和微博正文。微博三个话题进入阅读页的观测时间为 3.3～9.8 秒，同篇回开为 127 毫秒。

知乎重复图片已在 Find X7 Ultra 上复验。从知乎桌面站搜索原题，通过“读取当前页”进入 New，在回答目录选择“马甲”的回答。两次展开各显示 3 张图、3 个大图入口，收起时显示“包含 3 张图片”。Android 16 模拟器使用原帖留样也得到相同数量。

纽约时报中文网在手机网络上仍可能连接超时。
