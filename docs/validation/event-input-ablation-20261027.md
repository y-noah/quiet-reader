# 事件复核输入对照（未接入生产）

目的：检查序数数字写法与平台提问套话是否导致漏合并；不降低双向7.0门槛、不改变正式模型输入、不向生产评分缓存写入实验结果。

同一实际本地INT8模型对照三种输入：原始标题；仅把受限范围的中文序数/连续次数改成数字；在数字对照上再去除有限的“如何/怎样看待/评价”开头及“如何看待这一结果”等明确末尾套话。每组都保留原始标题的事实准入。合并装配和任务检索未执行，因此下面是“事实准入+双向评分允许”的计数，不是最终信息流合并率。

样本在运行前固定为已有16对公开开发样本（same7/different6/uncertain3），加10对新合成对照（same4/different6）。新增控制包括同公司不同任命人、同人不同公司、同城市不同发现、不同产品、不同连续年份和计划/完成状态。它们是开发者标注的合成控制，不能当作总体或真实用户准确率。
