# 瑞士轮赛事事实归组与默认来源（2026-10-26）

## 范围与原则

新增SportsEventEvidence，在既有EventGroups桥接阶段使用真实来源标题/摘要的结构化互证，不调用模型、不补写候选字段。不是把负的相关性分数调高，也不把所有体育标题转成一套万能身份。

首版只支持明确S编号赛季+瑞士轮、ASCII队伍代码及标题中的实际赛果。大小写/全半角统一；标题允许明确胜负动作或带队伍的比分。摘要只能补赛季/轮次及核对赛果，不能给没有赛果的标题制造赛果。逮捕这种俗称必须有摘要明确赛果佐证，刑事/假赛语境排除。

同一观察日、同赛季/赛制/双方的家庭必须：胜者唯一、至少一个明确轮次且唯一、至少一个明确比分且唯一、至少一份真实发布时间且与观察在同一北京时间日内。缺失细节只能被该唯一家庭补齐，不允许跨两个已知轮次/比分/胜者桥接。抓取时间只是共现窗口，不代替缺失发布时间。

标题或摘要中已覆盖的回应/采访/预测/条件/否认/辟谣/旧事/分局/性别项目等排除，标题与摘要明确结果、赛季或轮次冲突拒绝。V2EX身份优先，不参与本桥接。未知格式保留原样，不能宣称已识别所有隐含语境。

归组身份绑定规则版本、赛季/阶段/双方、胜者、唯一轮次/比分和观察日。保留候选ID、原URL、标题、摘要和元数据；不将抽取结果写成来源提供的新比分/日期，不叠加热度。EventGroups版本升级到explicit-thread-metadata-v5-swiss-results，沿既有前瞻策略指纹使旧准备失效；不改写旧冻结评价。

## 保留的失败与修正

swiss-flow-first.txt为12检查1失败：测试驱动在多次用户动作产生新快照后，错误要求原始旧快照仍存在。生产commitRanking本来只保留活动快照与最新两份，不能为了测试通过取消清理。驱动改为第一次拆分后检查仍保留的原成员不改，结束后检查旧快照已回收、总数<=3且当前分组有效；另补实际平台偏好代表选择。两轮15/0不抹去首轮失败，也不将其描述为生产归组缺陷。

## 开放边界

首版不是通用比赛解析器；中文球队名、其他赛事阶段、缺少赛季/轮次/比分、多人赛事、复杂赛后讨论及真实未覆盖语境仍不能据本轮通过强行合并。相同观察窗口并不证明任何两篇无字段标题属于同场。

这批7同事件仍有3漏项：卢拉连任低模型分、导演任命中文五与数字5、张雪水上漂标题数字省略及低分。新独立质量样本、本人推荐收益、全部账号全文、ARM整App峰值/发热/耗电及旧R8并发慢门槛继续开放。
