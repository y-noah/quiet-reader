# 热榜标题包装去重与数字事实保护

本记录是分组模块进展，不是全项目完成或发版声明。所有本轮安装均为电脑 API 36 模拟器 emulator-5560 的 discoveryprobe 隔离包，没有操作手机或普通包。未提交、推送、改默认版本或发版。

## 当前实现

- 只去掉明确的展示/提问包装：带冒号的热议/热搜/话题前缀、如何看待/如何评价等前缀、相应“一事”后缀，以及由问号/逗号等隔开的通用观点提问。核心标题至少十码点，保留原始标题及来源入口。
- 同一北京时间日期的弱元数据热榜可合并上述包装变体。保留来源热度原文、代表条目及全部成员，不叠加热度。V2EX 已知线程身份和跨日边界继续有效。
- 不删除否认、辟谣、是否属实、后续、调查结果或数字事实。数字之间的标点、百分号和数字前负号等保留，NFKC 全角形式可与半角形式对应。1.5% 与 15%、-15 与 15、1:2 与 12、版本 1.2 与 12 均不同。
- 数字弱标题使用新的命名空间。旧实现把 1.5% 和 15% 都压成 15，旧哈希本身无法恢复原事实，因此所有弱数字标题均不继承这类不可靠别名，包括裸整数。旧结构化反馈中捕获的原成员 ID 继续有效；只有不可逆旧分组哈希、没有成员的历史数字反馈不能安全迁移。
- 非数字且事实安全的旧包装别名继续参与锚点、分开显示、屏蔽及可见顺序恢复。反馈捕获先保留分组及全部原成员，再在既有预算内增加安全别名；“看够了”额外保留规范包装版本，实际新摘要/新事实可以重新出现。
- 前瞻评价准备记录加入分组策略版本，不能混用新旧规则评价；旧冻结记录保持可读。已知候选身份包含安全别名，既有身份预算继续严格执行。
