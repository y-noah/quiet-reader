# 虎扑回复来源时间基础（2026-10-28）

## 来源和实现

从已保留的公开来源 `artifacts/local-ai/hupu-public-audit-20261027/643330244.html` 的 `props.pageProps.detail.replies.list` 核对 `pid`、`createdAt`、`createdAtFormat`。最小 fixture 只保留前三条公开编号及时间字段，无作者、正文、账号或 Cookie；本轮未发起来源网络请求。原来源文件 SHA256 存于本轮 artifacts 目录。

`createdAt` 为 Unix 毫秒数；只接受 JSON 整数、2000 年至当前时间的范围，不转换字符串、浮点、秒数、相对显示文案或未来时间。不从 thread.repliedAt、抓取时刻或显示文案推算回复时间。

HupuDiscussion 已核对线程身份、当前页及权限后，才给实际保留的回复节附上 `hupu-reply-created-v1`。热门与普通副本的时间不一致时拒绝时间证据；主帖、过滤回复及未授权内容不附时间。沿用每个数组最多 2048 行的有界索引。ReadingHistory 按来源 URL、回复 ID 与版本组合验证读写，既有 ArticleDiskCache 快照及 DocumentSize 计费包含该字段。

正文版本从 2 升到 3，使在线旧正文重新获取元数据；离线旧正文仍可阅读，不凭空补时间。没有新数据库、模型、网络请求、定时器或兴趣学习。
