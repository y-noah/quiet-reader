# 同话题换帖与原候选反馈：阶段验证

本轮继续贴吧直达正文需求；仅指定 API36 模拟器，未操作手机或普通候选，未推送、发版。

## 实现

菜单选择不再 open(post,true) 打开独立子帖。Item 增加内部 selectedTopicPost，只能用于合法贴吧话题和规范主帖 URL；序列化进入当前请求及 Android 状态。原候选的 URL、标题、摘要和 metadataHash 保持不变。

原生 Repository 与 DynamicReader 使用同一目标选择函数：取得新的官方话题列表后匹配明确所选帖子；不存在就失败，不静默换成默认首帖。默认请求仍选择首个已知非视频帖。Document 保持话题/实际帖双身份，实际标题、回复、分页和图片会话继续来自实际帖。

缓存命中检查实际帖；在途请求、预读提升、跨 Activity 交接和图片所有权区分同话题不同选择，不能把默认帖的结果交给另一明确选择。读取反馈匹配原候选 metadataHash，因此有效阅读与快速退出都能关联原推荐，单击选择不产生正反馈。

换帖关闭旧评论与媒体、清除不匹配的锚点/展开状态。历史新增 bodySource，用于判断记录中的位置属于哪个实际帖；同帖可恢复，异帖不复用。失败页可返回上一可读帖，不新增重复话题返回栈；此恢复请求随配置状态保存。
