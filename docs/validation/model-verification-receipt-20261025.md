## 实现边界

ModelVerification在App私有模型目录中保存AtomicFile校验记录，绑定APK批准清单的SHA256、文件相对路径和该条目的预期摘要。首次仍完整读取每个文件计算SHA256。复用要求实际文件仍在模型根目录内、为普通文件且预期大小一致，dev/inode、uid/mode、size、mtime/ctime秒与纳秒全部一致。访问时间不参与，避免一次正常读取就失效。

API27以下、时间精度不足（ctime纳秒为0）或stat失败时不复用，仍完整校验。文件变化、缓存缺失/损坏或清单变化也重新校验。完整哈希前后身份变化拒绝发布记录；校验失败/取消不发布本轮结果。可选记录读写失败不使已经正确校验的模型不可用；后续重算。记录有64KB读写上限，位于版本目录内，随已有模型版本淘汰。没有常驻模型、模型池、新线程、后台唤醒或云请求。

此记录依赖Android App私有文件边界及文件系统元数据，不能描述为针对root或能同时篡改App私有模型与记录的同UID代码的认证机制。明确修复/安装流程仍验证原始文件，未用记录替代ModelFiles.repair。LocalModelEngine不再仅用进程内kind集合永久跳过检查；每次真正重新加载都重新核对文件身份。
