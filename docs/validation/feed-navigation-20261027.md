# 首页导航与下拉刷新（手机测试结束后）

依据用户早间反馈实现：向下浏览时隐藏顶部操作栏，向上浏览或滚动停止时显示；首页已在顶部时，新一次向下拖动可刷新。设置emoji齿轮换为20dp线条滑杆图标，圆点16sp。栏与操作区域仍保留48dp可达高度，未将触控范围随图形缩小，也未声称静止栏高度已经压至48dp以下。

FeedNavigationLayout仅负责首页手势与导航覆盖层，不添加新的来源/分类/状态文案。隐藏操作栏使用translation，不反复改列表测量高度；设置及来源页始终显示。只在手势起点已处顶部、纵向下拉超过阈值且松手时触发一次，与原圆点共用刷新/应用更新入口。短拖、横滑、取消、多指、加载中及非首页不触发；从正文中部滑到顶部须再次下拉。下拉结束恢复位移。整个实现不运行定时轮询。

操作栏采用覆盖布局，列表初始顶部padding为48dp。恢复实际child.getTop()时须扣除padding后交给setSelectionFromTop；页面返回、feed更新与自动增加可见窗口已统一处理。列表首屏初始化单独保留padding，不把首张标题放到覆盖栏下面。
