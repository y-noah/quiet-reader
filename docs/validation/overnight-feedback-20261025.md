# 晚间反馈实现与验证记录

本记录对应 `docs/requirements/overnight-feedback-20261025.md`。全部新增安装与测试仅针对电脑 API 36 模拟器 emulator-5560 的隔离包；用户拔线后没有操作手机。未发版、推送或提交代码。

## 已实现范围

- 首页只保留可点更新圆点与设置齿轮；设置改用首页相同的卡片及导航，一级五项，相关操作归入子页。来源信息压缩间距但保留菜单触摸区域。
- 深色背景、卡片与图标背景加深。正常正文去掉阅读提示；实际失败及摘要范围仍如实说明。
- 贴吧表情不再替换成统一占位文字，保留行内图片。完整真实图片解码矩阵尚待补测。
- V2EX 优先带共享 Cookie 的普通正文请求。知乎问答路径规范会话缓存身份，只排除明确的 CSRF/统计 Cookie；账号、设备、风控和未知字段仍参与校验。认证真机问题仍未证明修复。
- 热榜无摘要时新增同一天实质标题相同的分组，保留来源及各自身份，不叠加热度。不同措辞的同事件去重尚未完成。
- 单纯点击、曝光、加载、缓存不增加内容或平台偏好。正向阅读需要已显示正文、至少 20 秒前台有效阅读与主动滚动。
- QUICK_EXIT 独立弱负反馈：至少 300 字当前可读正文、显示后 0.8～5 秒主动返回、无前后台/焦点中断；排除加载未完成、登录受限及版本不匹配。7 天过期，可撤销；关闭学习撤回且拒绝后续写入。内容强度 0.35，平台每篇 -0.5，至少 3 篇不同文章后才产生小幅平台先验。弱信号不能覆盖明确偏好与合格阅读，沿用原有 4 个阅读样本预算。

## 已有有效证据

`artifacts/local-ai/overnight-feedback-20261025/summary.json` 严格汇总首批结果：477 个 JVM 测试无失败、错误或跳过；深色布局 74/0；320dp、1.5 字号布局 74/0；发现页交互重测 77/0；真实阅读 Activity 快速退出 6/0；反馈存储 12/0；会话变化 33/0。这些结果不等于真实个人推荐效果或认证内容验收。

真实公开 V2EX 同一话题普通读取约 1785ms，32 个区段、91 个块、31 条有作者回复，并命中正文缓存。强制动态路径此前出现约 16～23 秒超时及 Cookie 变化；公开读取成功不能证明实际账号受限内容或真机回访已通过。

## 发现过的失败及处理

1. 布局测试的空 contentDescription 比较引发测试驱动异常，已修复。
2. 320dp、1.5 字号齿轮裁切，改为固定 dp 图标字号，最终布局通过。
3. 设置中筛选后仍留在高级页面，已改为返回内容列表，交互重测通过。
4. 一次交互测试未在 5 秒 Activity monitor 时间内等到阅读页并超时；未改该超时的重测通过，但冷启动延迟根因尚未验证，仍需 ReaderStartup 专项检查。
5. 加深配色后旧颜色断言失败，更新对应预期，最终 JVM 测试通过。
