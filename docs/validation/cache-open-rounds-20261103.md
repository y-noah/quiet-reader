# 真实来源缓存逐轮计时（2026-11-03）

秒开定义：从触发实际首页打开逻辑起，到当前文章正文 DOM 就绪且 WebView 视觉回调完成，不超过 1000ms。未秒开数量包含超时/失败项，另列其中数量。

环境：Android 16 x86 隔离模拟器、debug 构建、真实公开榜单与正文；没有注入正文、替换请求或先等整批缓存完成。不是 Find X7 Ultra 的真机速度。

每轮打乱当批顺序逐条打开，随后走实际刷新动作。第一组立即返回；第二组正文可读后停留5秒再返回。第二组保留已有缓存及历史，不是与第一组相同冷缓存条件，不能把差异全部归因于停留时间。

说明：

- 计时不把阅读停留的5秒算入打开耗时；成功项耗时统计不包含失败项。每条等待正文上限为25秒，另有有限的DOM/视觉回调等待。timeout 仅表示限时内未验证到当前文章的文字正文，不武断归因为网络失败；纯图片正文不在此测量口径。
- memoryHitBeforeClick 是点击前内存查询；diskFileBeforeClick 只确认文件存在，不额外读取文件暖缓存，不代表文件一定有效。bodyOrigin 和 sourceWorkObserved 是观察值，不替代精确 HTTP 请求计数。
- 部分来源读取失败会被如实记录。本次 BBC 两组均未取得榜单，未将它算入正文打开成功率。知乎/虎扑真实账号不在本组范围。
- all-opens.csv 记录全部标题、URL、DOM/可读耗时、缓存线索和终态；non-instant.csv 只列未秒开项；两份 session JSON 保留原始结果。
- 探针基础设施完成不表示体验达标；未秒开和超时结果仍是待解决的问题。此次没有修改生产代码或发布新包。
