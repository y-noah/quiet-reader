# 普通启动空首页修复（2026-10-31）

## 故障及根因

用户报告“什么都加载不出”后，普通启动手机上的原候选首页只显示“尚无话题”。原插桩验收结论撤回，不以旧计数覆盖用户复现。

代码存在循环等待：DiscoveryActivity.defer 等待 feed() 设置 nativeFeedReady 后的首帧；DiscoveryController.accept 等待全部首轮正文持久化后才 feed()；cacheAcceptedBatch/canPrefetch 又因 ReaderStartup.pending() 不启动正文获取。测试预先完成阅读器准备或关闭自动来源抓取会掩盖它。

## 修改

- 冷启动/恢复没有已有列表时，先展示持久化排名中的原生十五条，再继续可选阅读器预热与正文缓存。首屏可见不代表正文已经提前缓存。
- 已有列表的手动换轮仍等待整轮正文持久化及回读，等待时保留当前屏；不取消此缓存门槛。
- 可选阅读器预热失败不再永久禁止缓存；实际 DynamicReader 创建失败通过已有失败回调收敛。
- 测试现在等 admission 提交完成再断言失败补位；不能把刚显示原生标题误判为缓存完成。
