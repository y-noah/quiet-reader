# 可选同池三顺序盲评

日期：2026-10-25。此项接通正式对比接口、Controller和本机评价库；仍为观察性配对会话，不是独立事件/时间留出。

## 生产流程

阅读偏好 → 本轮推荐评价 → 对比推荐效果。显式启动时暂停普通推荐与预取，从现有热门候选按生产基础顺序取最多100事件、冻结当前来源和画像版本，使用原LocalRecommendation预算和本地模型缓存整理三种顺序。完成后再次检查来源/画像版本；变化或计算未完成时拒绝开始评价。不会提交发现页快照或改变正在阅读的列表。没有内容兴趣时提示先选择兴趣，不虚构双模型结果。

基础、初筛、双模型各自前20事件取并集，最多60项。一个事件只问一次，候选内容统一取实际双模型结果中的主入口，避免三个顺序分别显示不同平台内容。并集通过SecureRandom打乱，结果顺序保存在SQLite中，中断继续不会再次洗牌。题目仅展示内容与平台，不显示排序模式、原名次或排序解释。完成后再显示三模式各自前排想看/不想看/未知数量；未知不算负例，不把单轮差异称为准确率或稳定收益。

paired_snapshot 与 single_snapshot 共用独立评价库的会话/标签表，无SQLite结构变更，继续保留最近30轮并清理孤立标签。paired记录含完整100以内候选池、三种顺序、模型revision、画像signature、策略及来源/画像版本，holdout_qualified固定false。写入前验证事件池相同且唯一、评价条目恰好等于前排并集、同一事件展示的候选身份/文字版本一致。评价不会写入兴趣/平台反馈。

取消、离开前台、刷新/更改偏好等取消正常模型操作时，也取消正在准备的盲评；epoch阻止迟到回调创建新会话。准备期间无后台重试。已进入评价的会话沿用SQLite中断恢复；准备完成但保存回调被页面销毁时，可在菜单继续已落盘会话。
