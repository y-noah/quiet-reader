## 问题及改动

旧EventClaimEvidence只比较全标题数字序列和粗粒度事实标记，可能允许相同数字交换角色。例如“10人死亡、20人受伤”和“10人受伤、20人死亡”，以及10人/10万人，均可能进入模型核验。新增五项产品行为测试先在旧实现运行，3项失败，原始baseline.log/xml保留；这证明准入保护有缺口，不是实际模型已经误合并的证据。

EventQuantityEvidence对每个候选预解析标题中明确的人数与死亡/受伤/获救/伤亡/轻重伤角色，比较两边均有的同一角色；数值规范化保留显式万/亿尺度。使用一次从左至右完整片段匹配，避免独立前后扫描把“10人死亡20人受伤”的句间边界读成“死亡20人”。只使用标题，不从摘要推断缺失角色/当前进展，不新增网络/模型任务。

该检查只否决冲突，未允许遗漏数字、删摘要事实或放宽动作/句式准入，不更改原模型输入、双向7.0、24对预算、完整连接及热度不叠加。claim revision升为v21以刷新证据身份；原始标题分数缓存仍可复用，但组装照常重新执行当前准入。精确同标题归组既有路径不变。
