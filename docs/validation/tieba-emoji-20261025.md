# 贴吧表情与顶部字号验证（2026-10-25）

## 实现

SourceParser 的图片地址选择依次检查 src、data-src、data-original，跳过 data/blob 等不可用占位地址，避免有效的后备地址被前一个非空占位挡住。无可用图片时保留来源给出的具体说明；没有说明则不输出孤立的 U+FFFC。有效表情仍以行内图片显示，通用无障碍说明不会成为可见的“[表情]”。

目视发现真实阅读位置问题：在页面顶部放大字号，旧逻辑锚定正文首段，把标题向上挤出。MainActivity.atReadingPosition 在顶部直接保留页面顶部；正文中仍按原有段落锚点保持位置。基线20项1失败，修复后20项无失败，截图中标题完整。
