# 兼容模型回退契约

当前APK的 `assets/local-ai-manifest.json` 是首选清单。`assets/local-ai-compatible-models.json` 中的 `manifests` 最多保存一个经过实际兼容验证的前版清单，类型是原始JSON字符串，必须保留原清单的字节内容（其SHA256就是资源与缓存版本）。不能在手机存储中自行发现清单并将其作为信任来源。

目前兼容清单为空：尚无另一套正式交付的模型资源版本可认可。当前版本资源损坏可自动修复；新安装没有前版文件时不能声称可以回退。以后更新模型，先验证旧模型与当前运行时、分词器和输入输出接口兼容，再把前版清单纳入此APK的明确许可范围。程序还要求schema、runtime、tokenizer_runtime、tokenizer_source_revision与当前清单一致。

安装首选版本失败时，选择器只接受已存在、ready且全部文件SHA256校验通过的兼容前版。选择后10分钟内暂缓重复拷贝失败版本；时间回拨到不合理范围不会延长该窗口。取消直接退出，不触发回退。用户手动修复成功清除该版本的暂缓记录。

运行失败也可使用同一兼容前版，但仅接受首选revision的MODEL_EXECUTION_FAILED/MODEL_NOT_INSTALLED；BUSY/非法请求不触发模型切换。worker加载失败仍先尝试原版本文件校验修复一次。进入回退检查后暂停新批次，保持原15秒前台计算窗口及资源监听；校验完成时再次核对时限/温度/电源限制，过期时保留已有结果。每轮最多切换一次，前版失败不再尝试首选版。没有可信前版或检查失败时保留当前可用匹配结果并结束，不伪装为整理完成。

实际切换在串行存储队列中清空本轮向量、logit、分组和计数，按前版revision重新读缓存；原版本SQLite派生缓存仍留在自己的键下。ITEM写入捕获实际取得revision，迟到的旧revision/batch消息拒绝。保持现有服务连接，由worker在新请求时先关闭旧engine再加载另一版本，避免RELEASE后立即重绑与100ms进程退出的竞态。进程死亡、8秒空闲退出、取消或原15秒到期仍直接结束，不自动重启循环。

主进程按实际选中的资源revision构建向量/精排缓存键，并将revision加入每个推理请求。worker仅从APK认可的清单解析该revision，切换时关闭旧engine；结果携带同一revision，主进程拒绝其他版本结果。清理时保留明确认可的兼容前版；不删除收藏、登录或兴趣反馈。

当前测试采用受控失败的新manifest和已有可信模型，验证生产选择函数、完整文件校验、暂缓、取消和无前版失败。真实跨APK升级回退、加载成功但输出质量回退、规则算法回滚仍需另外验收。不能把此测试称为这些场景均已完成。
