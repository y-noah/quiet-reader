# 文字热门来源默认供给 / 2026-10-24

## 问题与实现

用户澄清内容对象是文字流平台，视频原则上不要。原FeedStore新建时默认启用抖音、B站，即便最终排除整篇视频，仍会先使用网络及串行WebView读取这些榜单，开发和运行资源分配均偏离重点。

HotSourceCatalog新增TEXT_HOT作为文字取向热门供给：知乎、微博、虎扑、财联社、V2EX、百度、贴吧。FeedStore只在新数据库创建时采用此默认集。抖音/B站保留可选入口，明确启用后仍可采集；小红书、少数派、爱范儿原先没有通过核心热门供给契约，继续不默认启用。未把首页最新文章伪装成热门，不给文字平台额外热度分。

已有数据库不重写enabled，重新打开保留手动选择。未修改schema、排序算法、内容兴趣或平台先验；未删除登录、收藏、原网页或视频兜底。文字平台也可能含视频，TEXT_HOT是来源策略，不是逐条正文已经认证为图文；CandidateOrder和已有正文视频证据继续负责过滤。
