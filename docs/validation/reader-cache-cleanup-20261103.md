## 续测：发布保护解除后的缓存清理

发现：新一屏完成准备并发布后，磁盘中旧一屏的保护集合发生变化；如果当前加后续四轮的预读队列没有变化，原来的相同窗口短路跳过清理，旧文件延后到下一次换批才被清理。

修复：记录发布保护变化。即使预读窗口相同，也在存储线程执行保留集合清理；该分支不重启预读、不延长时限，不递增预读代次。旧屏在新屏准备完成前仍受保护。

新增检查实测窗口外文件被删除，并检查预读 deadline、代次、在途正文对象及请求计数均未改变。夹具曾因 Android API 写法和计数器类型发生构建/运行错误；修正后重新执行，原失败日志保留。
