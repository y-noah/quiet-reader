## 问题与实现

EventClaimEvidence更新claim-evidence-v11-release-specifications，新增包内ProductReleaseEvidence，只解析明确肯定的“主体发布型号”或“主体型号发布”完整句头，以及已覆盖的人民币起售价、屏幕尺寸/刷新率/类型、芯片和防水等级参数句。主体、带数字的完整型号必须字面一致；双方均提供的事实按属性逐项比较，不能以“数字相同”抹掉OLED/LCD、Pro/Max等差别。不推断缺失参数、别名、货币或数值换算。

仅允许已完整解析的两边把不同数字列表解释为可省略的参数或不同排列的已知属性。未知参数句、返券/销量/年份/含糊价格、不一致的重复起售价等不获得新放行；一边识别为本类产品发布时，不能绕回旧model-code-only分支放行另一边未识别的额外数字。时间、受保护事实、计划/疑问等原保护继续执行。

这是模型准入，不直接合并。原完整输入、检索、双向7.0、24对/分片时间上限、来源保留及热度不相加均不变。属性按候选提取一次；固定Pattern、数字检测不逐次编译正则，旧参数补充分支保持数字相同时短路。没有新增后台调度或网络；新增准入对可能增加预算内实际模型工作，不能称能耗零增加。原始标题分数key不变，当前证据key随VERSION变化重新验证。
