# 缓存满额替换计数修复 — 2026-10-27

## 问题与实现

ImageDiskCache和ArticleDiskCache在达到文件数上限时，把更新已有目标也当作需要新增一个最终条目。图片仅一个名额时无法替换，保留旧字节和旧获取时间；一般满额时会额外淘汰一个无关缓存。动作触发积极预读会更容易到达此边界，造成不必要的缓存损失。

目录扫描时记录目标是否已计入现存条目；替换无需额外最终条目名额，新增仍需一个。原目标字节仍计入临时副本的总空间预算，旧内容保留到原子发布/重命名；没有放宽字节预算、低空间或命名空间保护，没有引入线程、计时器、网络请求或模型推理。
