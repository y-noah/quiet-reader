# 微博文字流作者归属 / 2026-10-24

## 问题与生产修改

真实微博话题由多个独立原帖组成，原解析只在正文内部查作者，漏掉正文旁的卡片头部；实际新取得的分段标签全为“微博”。作者缺失也暴露正文相同的不同作者原帖可能被合并。

WeiboPost.author 现在只读取所属 `.card-wrap/.card` 内已观察到的移动端 `header h3.m-text-cut` 或桌面端 `.info a.name`，拒绝推荐区、引用/转发区、正文提及及嵌套另一张卡片的作者。无可信作者时保留“微博”，不猜补。SourceParser 使用“微博 · 作者”分段标签；同文无明确原帖续读身份时，作者参与去重与回退分段身份，不使两个作者共享折叠状态。已有明确原帖 continuation 身份不改变。

未把作者、时间、认证/客户端说明塞进正文或推荐画像；没有改变平台偏好、热度、登录会话、模型或数据库结构。改动仅影响新解析内容，旧阅读历史仍可恢复旧正文，未清空或批量改写。
