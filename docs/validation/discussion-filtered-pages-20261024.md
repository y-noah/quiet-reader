# 文字讨论经过全视频回复页 / 2026-10-24

## 缺陷与修复

上一轮虎扑统一续读为进展。本轮发现HupuDiscussion在后续页仅有视频回复时把过滤结果判为不可用，DiscussionPages也拒绝无正文页，且合并没有携带filteredSectionIds。结果是文字讨论可能被一页视频回复阻断，来源后页再次给出被过滤回复的配文时也缺少跨页排除记录。

HupuDiscussion现在允许身份/权限/请求页匹配且取得实际视频回复ID的纯过滤页；空白、来源不可用、无身份旧DOM仍不能冒充成功。usesStream承认这类已验证hupu-reply过滤ID。DiscussionPages合并保留过滤ID并排除同ID的讨论分段；只有取得新文字回复或新过滤身份才推进页码，重复旧过滤页仍报可重试失败。主帖不会被当成过滤回复删除。合并后的过滤计数/提示和排除身份通过既有序列化持久保留，不能把视频回复当作整篇视频或生成媒体附件。

可见回复加过滤身份共同受600项预算约束，并继续受正文2MiB序列化上限；超限整体回退，保持原正文、过滤集合和页码，避免无限翻纯过滤页。没有自动点击、后台预读评论或下载视频，没有调整模型/画像或登录逻辑。
