# 发现页单轮推荐评价：本机记录与恢复

日期：2026-10-25。此项是可选的单列表观察入口，不是三模式独立留出效果验收。

## 实现

- 阅读偏好中的“本轮推荐评价”可评价发现页列表、继续最近未完成评价、确认清除评价。入口明确写“评价发现页列表”，避免从来源/稍后读进入时误认评价对象。
- 开始时冻结发现页当前最多20个不同事件及候选副本，同时记录快照、来源版本、画像版本、筛选、模式及时间。后续列表变化不修改已冻结样本。
- 想看、不想看、不确定分别保存。不确定不算负反馈。返回可中断，前后台和页面重建可恢复。
- 独立 recommendation-trials.db，仅保留最近30轮并清理孤立标签。清除仅作用于评价记录，不写入或清除 FeedStore 的兴趣/平台反馈、收藏或来源数据。
- trial_schema=1、kind=single_snapshot、holdout_qualified=false；没有伪装成离线评估器的独立配对样本。

## 验证

通过 build-probe.ps1 -Offline -Target store 构建生产及 instrumentation，使用原签名安装脚本对日常 API36/emulator-5560 执行覆盖安装；未卸载应用或发布安装包。JVM XML 合计429项、0失败。

recommendation-trial instrumentation 使用每轮唯一诊断库和3条合成文字候选，未使用真实用户标签：

- 首轮14/0：冻结20条独立副本、三种标签语义、无效动作/索引/时间拒绝、SQLite重开、30轮淘汰与孤立标签清理、真实入口与按钮、Activity.recreate恢复、反馈隔离和清理范围。
- 扩展16/0：增加实际返回后通过菜单继续同一会话，实际HOME后重新进入并保留待评价项。
- 320dp宽（1080px/540dpi）、150%字号再执行扩展链16/0。通过标准无障碍节点点击，必要时按实际节点边界注入指针；可证明操作可达，不能据此声称完整视觉或TalkBack验收。结束恢复原420dpi与1.0字号。

## 未完成边界

单列表评价会受当前推荐曝光影响，不能计算三模式独立增益。三模式同池技术导出已有单独证据；面向用户的盲化去重采集、独立事件/时间划分、至少5会话/100不同事件真实标签仍待实现与采集。本轮未提供个人推荐准确率、双模型稳定收益、Find X7 Ultra整App内存或耗电证据。真实账号阅读等既有门槛保持开放。未提交、推送、发版或修改品牌。
