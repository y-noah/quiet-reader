# 排名前学习状态记录（2026-10-25）

本次补独立评价的前置证据，不是独立评价完成或推荐效果提升报告。当前对比和导出继续明确 holdout_qualified=false；严格评估器继续拒绝观察导出。用户目标仍为文字平台热门内容的个人化筛选。

## 实现边界

DiscoveryController 的显式对比请求在模型任务开始前调用 FeedStore.comparisonLearning。一个 SQLite 事务推进偏好过期水位并核对预期来源/偏好版本，读取所有反馈行（包含撤销与过期），按 at/id 顺序逐行摘要，保存完整历史指纹、当前有效反馈指纹、行数、最新反馈时间及截止水位。候选保存事件ID、每个归组成员的ID/内容hash和数据库 first_seen，拒绝已改变的内容或不存在的成员。当前可用候选/来源在计算后仍按原版本规则校验。

事件身份识别包括普通/版本化目标、read/saved目标和结构化归组成员；来源和实体主题不伪装成文章事件。撤销、过期、候选淘汰后，仍存在的历史反馈目标保留在 known_learning_identities。此集合是保守的已知历史身份集合，不是人工认定的完整训练事件集；不对其他URL、跨平台改写或语义相同事件作独立性保证。重置学习会按原功能删除反馈，指纹随之变化，不能拿重置后的资料继续同一固定协议。

RecommendationComparison 复制记录，向外返回副本；附加时验证版本、时间、事件池及每个成员的内容。RecommendationTrialStore 保存可选 learning_provenance 并验证事件池与代表内容。旧记录不必迁移且不补造历史。只在主动对比时读取此资料，不增加日常模型推理、网络请求或学习反馈。

导出器只输出允许的时间/计数/hash/身份元数据，不输出反馈正文、标题、URL或Cookie；新字段非法时拒绝整次导出。显式非独立标识保留，不能由这些字段自动升级为独立验证。反馈最多100000行、已知身份10000项、对比100事件、单事件5000成员；超过上限拒绝，不能截断后假称完整。
