# 完整元数据不能覆盖明确讨论身份

## 缺陷与改动

EventGroups原先仅在摘要/日期不足时使用V2EX帖子ID；完整元数据先进入exact-evidence分组。因此同帖更新标题/摘要可能拆开，而不同帖子复制相同完整元数据可能误并。新增两项回归在原实现上均失败（514项中2失败），原始日志及XML保存在event-similarity-20261026下的thread-identity-before文件。

当前归组首先使用已验证的V2EX帖子路径与reply数量锚点。查询、未知hash路径、非官方host等仍保留原候选身份；原URL和candidate.id不改。不同明确帖子ID不被相同完整文字合并，同帖不同元数据仍保留全部原入口。该修改不声称解决跨平台不同措辞事件的语义归组。

保留既有跨平台完整证据能力：同一完整元数据仅对应一个已知帖子，且该帖只有一个完整证据组、另有非V2EX来源提供完全一致证据时，可桥接同一事件。两个明确帖子共用文字，或同帖存在多个冲突完整证据组，均禁用该桥接，避免通过新闻副本间接合并两个帖子。无摘要标题桥接继续执行原边界。

## 历史兼容与新反馈隔离

旧完整证据hash仍是只读兼容别名，含1.5%等事实数字的完整原文hash也保留。旧目标若已丢失原成员且内容已变化，不伪造迁移。

发现首次修订后，新单帖反馈若捕获全部旧别名，会经共享旧文字hash隐藏另一独立帖子。新增隔离回归确实失败（517项中1失败，原日志/XML保留）。现EventTargets捕获V2EX新反馈时只写当前明确帖子别名、实际成员身份及当前事件身份；读取历史记录仍可识别旧别名。单帖BLOCK/ENOUGH不再扩散到不同帖子，结构化分开、版本看够了、撤销继续保留。真实多来源事件仍捕获实际分组身份和全部已观察成员。

策略版本升级为explicit-thread-metadata-v4，旧前瞻准备失效；冻结的旧记录不重算。
