## 来源与实现

公开脚本 artifacts/public-sources/tieba-pb-20261026.js 中，.pc-pb-box 是滚动容器，回复使用 t-virtual-list 及稳定的 .pb-comment-item[data-id]。向后滚动由来源自身加载，不是旧分页链接，不能伪造 pn。已加载全部评论标志仅表示来源取得数据，不能保证虚拟行均被阅读器采样。

- StructuredSources 保留有效数值回复 ID；正文、楼中楼及无有效 ID 内容不冒充可追加主回复。回复正文旁归属明确的图片列表纳入回复，侧栏图片排除。
- TiebaReplies 复用正文来源 WebView，以 65% 视口重叠滚动；每批最多12次采样、20秒。沿用来源正常加载，不新增隐藏接口或读取账号存储。
- 仅合并当前实际帖同页的新回复 ID，保留主帖、已读回复、原热搜身份及解析记录；沿用600条回复、2MiB单正文边界。
- 结束还要求遍历到来源实际底部；登录遮挡与加载错误保持独立状态。
- MainActivity 虚拟帖触底走此管线；缓存命中按需重建来源。后台/关闭/销毁释放来源所有权；账号、缓存命名空间和清理代次变化拒绝旧回调。
- 历史、缓存、拷贝和指纹保存虚拟类型。修正 ArticleDiskCache 异步快照遗漏 sourcePostId，防止缓存恢复后回复失去身份。

## 开放边界

以上不等于实际网站及真实账号验收。仍需实际匿名来源跨首屏回复增量、MainActivity自动触底/阅读锚点/短页、窄屏深浅视觉、来源交接/旋转完整流程。重建来源后较长已读列表可能用完单批预算，需要保留内容并允许重试，不能宣称所有帖子无等待续读。
