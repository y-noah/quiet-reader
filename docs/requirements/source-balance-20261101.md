# 来源覆盖与开关语义修复（2026-11-01）

## 依据
手机只读核对：首15条全部为百度；实际候选池包含10个来源。用户明确对百度、微博多次选择少看。视频源开启但曾无采集，随后采集成功仍遭全局video过滤。此问题不得以候选池数量偏差或用户兴趣推断为合理行为。

## 行为边界
- 不修改去重、不重置兴趣、登录或阅读历史。来源开关是硬边界。
- 已启用的B站/抖音允许视频元数据进入推荐，默认仍关闭。用户本机按要求关闭两者。图文来源的纯视频过滤保持；图文内附视频仍由原阅读器处理。
- 视频正文按需打开，不为提前展示卡片下载视频、不伪造正文缓存成功证明。
- 内容兴趣分层优先。分层内部按投放历史轮换，并在每15条中避免大供应源垄断。至少三个同兴趣来源时一般最多5条/源；两个来源时8条；明确少看来源一般最多2条。供应不足则软放宽，优先放宽非少看来源，单源筛选不缩水。
- 不加总跨平台热度、不为海外来源增加分数；不把候选数量当受欢迎程度。
- 本轮发布、预备队列、模型候选和快速刷新使用一致的来源分布规则。源内次序稳定。有限池子仍可能重复，不能承诺无限新内容。

## 海外中文来源
加入纽约时报中文网官方每日热门：主页公开的 /async/mostviewed/all/?lang=zh-hans，使用daily次序，不混入weekly或把RSS当热榜。只接受cn.nytimes.com的中文文章路径，不获取英文/双语页面，不绕过订阅。正文来自公开HTML的article-body-item/article-paragraph，保留图文、去广告栏，校验canonical身份。不正常时走现有来源页退路。
数据库10→11只增加来源行，保留所有开关和用户数据。新源默认开启，可关闭且重启不重新开启。BBC继续可用；RFI被403阻挡、DW尚未确认可靠热门数据、早报全文资格不完整，本轮不加入。

## 验收
1. 复现旧的来源集中和准备队列，首轮及连续轮换不会在多源同兴趣供应充足时全部为百度。
2. 明确少看不被轮换新鲜度覆盖；内容负向不能仅为来源多样性上浮。
3. 全量回归、随机历史排序、预备队列无重复身份、不丢候选；关闭视频源立刻不可选，开启后可选。
4. 数据库升级保留原开关，新源开关持久化。
5. 三篇公开中文热门文章逐段核对；手机正式阅读器实际显示，首页连续刷新停止动画并展示多源。
6. 手机仅关键几次验证，清除测试工具和临时文件，恢复屏幕超时。
