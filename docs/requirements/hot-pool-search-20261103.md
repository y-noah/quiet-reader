# 热搜池搜索与首页20条

## 范围

- 首页顶部增加紧凑搜索入口；不增加横幅、分类、无限加载。
- 首页每轮最多20条，有效供给不足时不填重复条目。
- 查询已启用来源的整个 active 候选池，不限首页、预缓存队列、当前来源筛选或已读状态。
- 本地候选表最多5000条，包含 inactive 历史记录；这个上限不是当前有效池数量。
- 已关闭来源、被明确屏蔽的内容、现有语言/视频政策排除的内容不进入搜索。主动搜索可以找回标记“看够了”的话题。
- 搜索页空输入显示实际可搜索条数；搜索匹配标题和简介，不扫描正文，不请求平台全文，不联网扩展，不生成回答。

## 匹配与交互

- Unicode宽度、大小写、标点归一化；标题精确匹配优先，随后标题包含、多个关键词、短距离分散词和保守错字匹配。
- 短词不模糊扩展；带数字的查询不容错，防止型号、金额或年份串词。不是通用语义问答，不保证同音或同义句识别。
- 输入最多80字符，停键250ms开始在存储线程搜索；过期请求不发布结果，后台/退出页面取消待执行输入任务。不运行额外模型或调用API。
- 搜索列表复用现有阅读卡片和统一阅读器，显示已读浅灰，不截成首页20条。
- 有匹配显示结果，无匹配明确显示“热搜池里没有相关热搜”；空池、存储读取失败分别提示，不能把失败假报为没有热搜。
- 搜索不记录曝光、兴趣或平台偏好，不改变首页批次与滚动锚点。实际阅读继续沿用现有阅读反馈规则。
- 当前屏+4轮后续队列的容量随每轮20条计算；预取仍串行，原时间预算、后台停止与热量/电量限制保留。

## 验收

- 查询能命中首页20条与预缓存队列以外的内容、非当前筛选来源的内容、已读文章。
- 明确验证空查询、零结果、少量错字、多关键词、数字短词误匹配、分组内其他来源命中、稳定排序和全部匹配结果。
- 实际Android界面验证快速切换关键词不回填过期结果、清空输入显示真实池数量、返回首页仍20条、滑到底不追加。
- 来源均衡、当前屏与4轮预备队列无重复的测试随20条同步，不能仍使用15条配额验收。
- 真机升级与外网全来源缓存速度不由模拟器搜索测试代替；本轮不自动占用已经归还的手机。
