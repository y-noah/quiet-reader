# 中文AI来源、平台软偏好与60条推荐池

基线：1.0.22 / 1413552。用户本轮未提供手机，只做本地与隔离模拟器验证，不据此宣称真机验收完成。

## 需求及边界

- 增加可免费阅读全文的中文AI技术来源，使用既有统一阅读器、图片和主动缓存，不增加服务端、API key或模型。
- 平台“少推荐”降低选中机会，不能作为关闭来源的隐藏开关；真正靠前的热点可以部分抵消平台惩罚。重复点击不复利压低到零。
- 用户已澄清数量：每页仍为15条，总推荐窗口由75降为60，共四批；不是首页显示60条。搜索继续覆盖已采集的完整候选，不能只搜索当前15条。
- 关闭来源、屏蔽及明确不喜欢的话题仍执行原有排除边界，热度不能绕过它们。

## 来源

1. 量子位：只取官网明确的“热门文章”侧栏，不把整页所有文章混入榜单；正文限定文章区域，剔除标题元信息、分享和相关阅读模块。
2. 雷峰网人工智能：只取AI栏目及其人工智能学术/开发者文章入口，不纳入其他数码栏目。准确标为最新AI文章，不虚构热度；正文限定原文区域，移除课程推广横幅和推荐模块，恢复lazy图片真实地址。
3. 机器之心当前返回数据服务站点，未得到适合本轮接入的公开文章供给，因此不硬接。
4. 新URL只接受明确的官网域名和文章路径；拒绝伪装域名、登录页和无关栏目。13→14迁移补充新来源、清除废弃的整数配额，不修改旧开关、登录、已读和反馈。

## 选取策略

- 去掉持久化的“平台整数上限”和取整截断，平台少推荐不再从候选池删除文章。
- 平台基础权重：默认1，明确少推荐0.5，多推荐沿用1.75；弱阅读反馈仍保持较小影响，连续反馈取最后的明确决定，不连乘。
- 热度使用真实热榜的榜内名次归一化，不比较/叠加不同单位的原始热度。非热榜来源的列表位置不算热度。
- 对少推荐平台，榜内前三话题优先进入该平台队列；热度可部分抵消惩罚，补偿有上限，不能把该平台所有普通话题一起抬高。
- 平台份额仍与来源条目数量无关；分不开的名额随真实展示轮次轮换，不能总由同一个枚举顺序获益。选择完成后均匀穿插各来源，避免集中连刷。
- 未展示过的话题新升入平台头部热榜，可重新参与竞争；已经读过的原文继续排除。

## 窗口、缓存和验收

- 推荐窗口60，首页15，后续最多45；预取任务总上限同步从75降到60，不改变串行并发、后台生命周期或已有耗电预算。
- 展示轮回与模型选择额度分开记账。回放未读内容不能把模型的额度重置，导致已被窗口淘汰的旧尾部又填进来。
- 未打开的旧内容和新到内容共同占用60条上限：优先选择未展示的新候选，旧的未读内容只补充剩余位置，不能把新条目叠加到原先60条之上。
- 验证：真实来源列表/正文、旧数据库升级、旧零份额、重复少推荐/撤销/多推荐、热点升榜、内容屏蔽边界，以及四轮60条、耗尽/已读/新到内容/重启恢复。
- 候选包先留本地。真实设备的触控、内存、温升和登录验证待用户方便时完成。
