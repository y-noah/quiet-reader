# 海外中文热门来源接入契约（2026-10-26）

用户已授权：寻找有一定读者基数、能参与国内来源统一排序、可免费取得文章内容的外国平台，有合适的就加入。此次授权覆盖之前“只是好奇、不加入”的限制。

## 选择与范围

首个接入BBC中文：成熟中文新闻服务，使用官方简体“热门内容/热门阅读”榜。当前实际10条，不拿首页编辑精选、最新文章或英文榜替代热榜。接入理由是长期中文媒体与可验证公开热门入口，不声称已验证具体中文活跃用户数。

默认榜单 https://www.bbc.com/zhongwen/popular/read/simp ；来源页 https://www.bbc.com/zhongwen/simp 。无服务器、第三方转发、翻译服务或API Key。网络跟随设备已有连接；App不配置VPN、不自动重试绕过访问限制。用户仍可在设置→内容来源关闭。

## 热门候选与推荐

只接受BBC官方中文mostRead数据、明确文章身份与官方名次；保留简体标题和实际文章发布时间。不要伪造阅读量、全网总热度或受众数量；原始跨站阅读数不相加，不给予国别/平台额外加分。进入现有CandidateOrder、去重、本地双模型与平台偏好流程，不恢复总榜或增加海外专栏。个性化最终顺序仍由现有兴趣/明确反馈决定；官方名次作为已有中性回退顺序。

## 正文与媒体

仅支持 www.bbc.com/zhongwen/articles/{id}/simp 或 /trad 中文文章。校验pageProps服务、状态、语言版本、路径、metadata文章类型及optimoUrn一致后，提取本篇content.model.blocks。正文、段落、站内外普通链接、图片、图注和小标题进入统一阅读器；不运行网页脚本，不混入侧栏、广告、播客推广和相关阅读。

简体榜保持简体，文章中的繁体站内链接可读，不将两种语言的榜单各算一份热门供给。不支持的页面/身份冲突/空正文显示来源不可用，绝不用摘要或整页文字顶替；遇未知正文块类型也拒绝静默生成缺失部分的正文，已知推广块按明确名单忽略。

普通文章附带视频保留原位置、真实封面和紧凑来源入口；播放器地址不透明时不调取播放器API，不预取媒体、不创建解码器。纯视频页面类型不作为文章接入。正文图片走现有会话隔离与主动预缓存，正常图片和视频封面都使用统一布局。

## 持久化与验收

推荐库6→7只增加BBC来源行，INSERT OR IGNORE保留已有配置；不清除收藏、阅读记录、兴趣反馈和其他来源开关。用户关闭后重开不能被默认启用覆盖。

必须核验：官方10条身份/顺序/发布时间、真实免费正文与段落尾部、不同语言链接/错误身份/未知结构、统一阅读和配图、无播放初始化、预读不记兴趣、磁盘恢复不重复写、来源偏好/屏蔽、旧库迁移与已有功能回归。网络失败走现有失败状态、缓存保留与退避，不伪称获取成功。真实样本不是全站永久结构或手机资源验收，独立推荐效果及整App资源门槛仍按主需求执行。
