# 十角色循环体验验收

用户目标：完成来源份额修复后，至少10个28岁男性、INTJ模拟角色，各至少20轮刷新查阅，发现问题修复后重测。人格信息仅为角色描述，不作为偏好预测。角色并非真实参与者，报告不得伪称真人满意度。

## 角色
|ID|关注/偏好|平台偏好|体验重点|
|--|--|--|--|
|01|冷启动，无历史|全中性|来源数不影响曝光，余数公平轮换|
|02|开发、AI、硬件|多V2EX/IT之家，少微博/百度|平台份额与正文优先级|
|03|经济、公司、产业|多财联社，少贴吧/微博|标题简介、时间、误触后返回|
|04|社会公共事务|多知乎/澎湃，少百度|避免同一来源刷屏、阅读连贯|
|05|国际与海外中文|多BBC/NYT，少微博|中文与正文完整、免费阅读|
|06|体育与赛事|多虎扑，少财联社|讨论正文与回复、长文返回|
|07|文化、科学、教育|中性平台，按内容多/少看|内容偏好不等于固定平台|
|08|社区实践经验|多V2EX/知乎，少百度|平台混合、冷暖缓存|
|09|低娱乐需求|少微博/百度，其他中性|少看低于均值而非每轮保底2条|
|10|重复敏感、短时浏览|中性，逐步少看实际低兴趣内容|连续刷新、额外名额、返回锚点|

## 轮次定义
每轮必须在隔离模拟器的实际首页刷新，记录最终候选身份与来源/偏好份额、刷新耗时/状态，选择本轮可读内容进入实际统一阅读器，观察正文与滚动，再返回首页验证位置与列表稳定。单纯断言或随机排序不计一次体验轮。每角色至少20个完整轮次。

公开热榜回放样本与实时网络测试分开标注。若使用已获取的公开HTML作离线正文，标明离线回放，不把缓存命中速度冒充真实网络获取速度。受限来源不得伪造登录成功或完整正文。公共文章数据可用于选择体验主题，测试角色的模拟偏好只写隔离数据库。

本轮固定样本共281个候选，来自11个来源；公开HTML经App真实解析器筛出63份可读正文。微博、虎扑当前采集分别受403/405限制，热榜部分使用明确标注的既有公开捕获；知乎公开正文请求403，不用其受限正文冒充登录成功。每个独立角色重设观测时间以构造有效回放池，原始抓取记录另存。图片仍可能真实联网，不能称完全离线。阅读行为学习关闭，防止机器快速打开/返回被当作真实兴趣；明确的角色偏好与第10轮少看操作仍写入隔离数据库。

## 记录与改进
输出每轮JSONL：角色、轮次、内容标题/平台/身份、选读内容、耗时、重复比例、兴趣匹配依据、UI状态、问题、所用构建。审阅每个角色的20轮结果；优先修复可复现的明显故障，不凭标签臆造主观评价。每次修复保留失败证据、复测相关角色，并以最终构建完成至少200轮总体回归。

测试工具必须在 WebView 视觉状态回调后确认屏幕正文区域有实际内容，滚动后再检查一次；仅有 DOM 文字不算显示通过。早期只做 DOM 检查的记录归档，不计最终验收。文化科学角色需先取得真实模型生成的 personal 快照，逐轮仍记录实际模式，不能把随后采用的 cold/platform 保底排序宣称为模型精排。快速刷新和进入正文可能中断后续模型整理，测试不为凑结果伪造向量或偏好。

手机只做少量关键验收，不在用户手机运行200轮。结束清理测试工具、恢复屏幕设置，保留验证后的最新版。未经请求不推送、不发布GitHub Release。
