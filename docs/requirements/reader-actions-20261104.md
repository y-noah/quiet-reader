# 帖子操作与回答阅读调整（1.0.4）

## 范围与行为

1. 帖子更多菜单只保留重新读取、来源/登录、回答/楼层目录及适用的同话题帖子操作。移除字号、外观、阅读设置入口；首页设置中的阅读外观继续统一管理。
2. 帖子顶部增加视觉20dp、触摸区域48dp的独立分享按钮，调用Android系统分享面板，内容为text/plain原文URL。普通内容使用来源链接；贴吧话题使用当前已选择/已显示的原帖链接，不能分享内部reader地址或话题目录冒充原帖。不自动发送给任何联系人。
3. 可折叠回答/长评论只有一个操作入口：未展开时显示展开；展开后，在本节底部提供粘性收起按钮，长文中途及末尾可触达。收起控件采用32dp薄型底色与轻量文字，触摸区域保持至少48dp，去掉厚重胶囊边框。删除下一条回答等重复跳转按钮。
4. 展开与收起只替换当前section的自有HTML，不重新加载整个WebView，不重新请求来源正文。收起后当前摘要定位在可视区域，下一条预览自然接在下面。保留其他回答展开状态、图片、主题、字号和已读记录。
5. 原有目录仍可直接跳转指定回答；回答续读/楼层分页沿用现有自动加载，不强行展开下一条、不添加额外后台轮询。

## 边界与验收

- 空正文或读取中也可分享有效原文地址，缺失或跨来源无效地址不能发起分享。
- 贴吧当前阅读原帖和当前话题的缓存身份分别校验，不分享上一条帖子的地址。
- 收起不创建浏览历史层级，六轮连续展开/收起保持readerPageUrl不变，下一条预览可见，单节不会出现两个折叠入口。
- WebView更新失败才回退现有安全重绘路径；导航或页面代次变更后忽略旧回调。
- 必须验证默认和大系统字号、深浅色、长回答中途/底部、原文链接意图、移除通用设置且保留来源操作。
- 模拟器为自有合成正文，分享面板被测试拦截，不发送消息。真机连接后另外记录真实话题验收，不能把模拟器结果描述为真机验证。
