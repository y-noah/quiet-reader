# 平台偏好 / 2026-10-24 用户需求增补
> 2026-10-25后续变更：用户移除稍后读入口与保存操作。下文SAVED仍描述旧数据的有效期、撤销及兼容语义，不要求生成新的保存操作或恢复稍后读界面。内容与平台的显式偏好、合格阅读弱参考保持有效；首页分类导航已移除。


用户明确要求：模型不仅记录类型偏好，也记录平台偏好。内容兴趣与平台偏好分别建模，平台并不具有开发者预设的偏好权重。这里是需求与当前方案，不是推荐质量已验收声明。

## P01 记录真实来源

每条新的有效阅读、稍后读、内容多看/少看和兴趣选择事件保留实际来源。聚合事件从哪个来源进入阅读，就记录哪个来源，不能向全部聚合平台广播。数据库反馈表增加source列；旧事件未知来源保持空，不根据当前页面或已变更候选猜补。模型不读取Cookie，反馈不上传服务器。

验收：实际阅读事件同时进入内容画像并保存实际source；旧库升级不丢收藏/反馈/快照/向量；未知旧来源不生成平台倾向。

## P02 显式平台选择与行为弱参考

来源菜单和内容卡片分别提供平台多看/少看。scope=source的最新有效MORE/LESS是显式选择，可撤销、重置；与“多看/少看这类内容”的sample事件区分。只改变推荐倾向，不关闭来源或删除登录。

合格READ仍需已显示正文、前台至少20秒和主动滚动；7天失效，关闭阅读学习时撤回。SAVED仍14天失效，移出稍后读撤回对应事件。普通内容MORE/LESS也可作较弱来源观察，但不能从一篇不喜欢的文章推断讨厌整个平台。至少三个不同文章身份才形成行为平台参考；同文重复打开、改版或READ/SAVED/反馈多动作只能算一个文章。已排除的预取、登录等待、后台、视频、单纯点击和未点击均不能增加平台倾向。

验收：一次阅读不改变平台整体倾向；三个独立文章可形成弱倾向；重复动作/版本不累计；显式平台少看不被大量阅读覆盖；关闭、过期、撤销与重置同时作用于内容及其平台证据，不留孤立来源计数。

文字可见就绪补记：统一阅读器经实际可见帧确认的文字不应等待慢图片或整页onPageFinished才开始计时；保留20秒、主动滚动、前台和正文版本匹配限制。只有图片占位而无文字时不因首帧就绪提前计时。预取及仅显示页面仍不产生反馈。实现证据见 `../validation/visible-text-interest-20261024.md`。

## P03 排序与模型边界

平台偏好是本机推荐画像中的独立小先验，不把“知乎/V2EX”等平台名当成内容主题交给embedding/reranker，也不增加第三个模型。内容相似度与精排保持原双模型路径。平台反馈本身可直接调整顺序，不为此唤醒模型。

当前初版：显式来源选择score=±1；行为参考绝对值不超过0.35。行为事件按文章身份去重，READ=1、SAVED=1.5、内容MORE/LESS=±2，至少三篇后按sum/(篇数+8)并限幅；显式来源选择优先。只对个人候选顺序/同一内容分类档位内的最终模型结果微调排序键，偏移为4×score（弱参考最多1.4）；双方相反偏好可产生最多8的相对键差，不等于承诺单项实际只移动4名。不得跨越明确内容负反馈档位。此参数是初版设计，个人效果需真实使用评估。

来源热度、转载数、抓取次数不进入平台分数，同事件多个来源不相加。事件已合并时，可优先选择其中实际偏好的来源作为默认阅读入口，保留全部合法入口。已过滤视频/非中文/停用/屏蔽来源不能被偏好重新引入。最新时间模式保持时间顺序，不叠加平台微调。模型输入从未应用平台微调的候选基序开始，最后只应用一次，防止双重加分。

缓存实施补记（2026-10-25）：精排原始logit只依赖模型版本及实际query/候选输入对，不以整份画像或平台偏好签名作为失效键。当前向量和输入对齐备时，平台偏好变化可复用两模型缓存而不提交推理；候选、query、模型变化或缓存缺失仍按需计算。每轮仍根据当前反馈重建分组、负反馈约束和平台融合，不缓存最终个人惩罚或沿用旧排序。真实两模型基线和复跑见 `../validation/rerank-pair-cache-20261025.md`。

验收：source-only事件不增加语义样本；偏好变化令画像/排序缓存失效；最新排序不变；来源偏好不能盖过明确内容负反馈；合并入口只选取现有来源、不加事件热度；无偏好时保留原顺序。

筛选交互修复补记（2026-10-25）：分类或来源视图优先保留已选且仍符合条件的主入口，不因原entries首项不同丢掉平台偏好；明确筛选不兼容时才回退到符合来源与分类的组成员，回到全部来源可恢复冻结快照主入口。SQLite分别反序列化时按身份/版本判断，不靠对象引用。JVM429/0，实际页面和持久化组合7/0、已有分类回归18/0；详见 `../validation/filter-preferred-entry-20261025.md`，非真实用户推荐质量证据。

## P04 管理与解释

来源页菜单提供“多看这个平台/少看这个平台”，内容卡片提供调整当前默认阅读平台的入口。反馈记录明确标识“平台偏好”，可撤销恢复前一条有效选择；重置同时清除两种偏好但保留稍后读及平台登录。影响排序的行包含“参考平台偏好”的说明。

2026-10-25反馈管理增补：反馈记录按最近优先展示，支持全部/内容偏好/平台偏好/阅读弱参考筛选；仅管理显示顺序反转，不改变按事件时间重建画像的顺序。列表提供短预览，详情保留完整样本、记录时间及适用的失效时间。点击记录先查看，不立即撤销；确认后只撤销选定id，保留其他反馈、登录和收藏；返回记录保留筛选。空分类仍可切换筛选。实施与失败记录见 `../validation/feedback-management-20261025.md`。

初版已实现以上入口；真实长期兴趣效果、更多平台样本、卡片入口的全部主题/字号/无障碍仍须继续验证，不以一个原生菜单通过关闭整体UI验收。

实施及精确证据：`../validation/platform-preferences-and-v2ex-20261024.md`。原主需求其他范围与统一阅读U01–U05保持有效。
