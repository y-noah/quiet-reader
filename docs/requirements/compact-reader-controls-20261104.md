# 紧凑搜索与阅读控件（1.0.5）

## 行为

- 首页搜索入口与搜索页输入框使用同一30dp可见底色高度（48dp布局内上下各缩进9dp），字号13sp，入口搜索图标14dp。保留文字提示、全池搜索范围和既有查询行为。
- 阅读页分享图标18dp，点击区域48dp；分享仍走原文URL与系统分享面板。
- 展开回答末端的粘性收起入口改为靠右的双上箭头图标，不显示“收起”文字。圆形底色约30dp，图标16dp，实际操作区域48dp；aria-label和title保留“收起当前回答”。
- 同一回答只保留一个展开或收起入口；沿用原位替换section和收起后显示下一条预览的逻辑，不新增下一条跳转或网络请求。

## 边界与验证

- 检查深浅色、320dp窄屏和150%字号，不依赖文字字符充当图标。
- 验证重复展开/收起、长回答中途与末尾可触达、页面身份不变、分享地址正确、全池搜索可用。
- 手机未安装知乎，参考公开设计资料关于小型悬浮图标及靠边放置的思路；不能声称复刻或验证了当前知乎App版本。参考：https://zhuanlan.zhihu.com/p/68505595 （2019年设计分析）。
